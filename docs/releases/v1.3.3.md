# Polyant v1.3.3

Polyant v1.3.3 is a patch release. The agent icon can be uploaded again on
deployments with the default Content Security Policy, the embedding dimension
can be chosen with the embedder, and a set of resource leaks and stale states
found in review are closed. There is no v1.3.2 of Polyant.

## Highlights

- **Agent icon upload works under the CSP.** The icon cropper loaded the picked
  file through a `blob:` URL, which `img-src 'self' https: data:` blocks, so
  every upload failed. It now decodes the file without loading a URL.
- **Selectable embedding dimension.** The agent's Embedder panel has a
  Dimensions select, fed by what the embedder supports (OpenAI: 1024 or 1536).
  Changing it deletes the agent's memories and knowledge base, as switching the
  embedder does, and asks for confirmation first.
- **Fewer leaks.** The channel manager stops the message coordinator on
  shutdown, expired webhook triggers are swept, the Telegram reader lock and the
  speech-to-text abort listeners are released, and outbound HTTP closes its
  per-request agent.
- **Quieter logs.** A 4xx response is logged as a warning, a 5xx as an error.

## Breaking changes

None. `PATCH /api/instances/:slug` accepts a new optional `embeddingDim`; a
value the embedder cannot emit answers 400, and a change requires
`confirmWipe: true` when the agent has memories or documents.

## Security

None.

## Upgrading

No database migration and no new configuration variable.

1. Run `npm ci`.
2. Run `npm run build`.
3. Restart the services.
